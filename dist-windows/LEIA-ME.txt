BAMBOLINO BONJOVEE — Como rodar no Windows
============================================

FORMA MAIS SIMPLES (recomendada): bambolino.html
--------------------------------------------------
Um único arquivo HTML, sem instalar nada (sem Node, sem Python, sem Git).

1. Baixa só o arquivo "bambolino.html" (não precisa da pasta toda).
2. Dê DUPLO CLIQUE nele — abre direto no seu navegador padrão.
3. Clica no microfone, fala, espera a resposta. Pronto.

Aviso: nessa versão a chave da Anthropic fica dentro do próprio arquivo
(visível pra quem abrir "Inspecionar" no navegador). Certo pra uma máquina
específica sob supervisão (como um quiosque de mostra cultural) — não
compartilhe esse arquivo publicamente.

A voz usa a síntese nativa do navegador (um pouco mais robótica, mas
funciona sem instalar nada).

------------------------------------------------------------
FORMA ALTERNATIVA: bambolino.exe (+ pasta public/data/.env)
------------------------------------------------------------
Mesma interface, mas roda um servidor local — precisa da pasta inteira
(bambolino.exe, public\, data\, .env) junta, não só o .exe sozinho.

1. Renomeie ".env.example" para ".env" e cole sua ANTHROPIC_API_KEY nele.
2. Dê duplo clique em "bambolino.exe" — abre uma janela preta (não feche)
   e o navegador abre sozinho em http://localhost:3000.
3. Se o SmartScreen bloquear, clique em "Mais informações" → "Executar
   assim mesmo".

Voz (opcional, pra ficar mais natural que o .html): instale o Python
(https://www.python.org/downloads/, marcando "Add python.exe to PATH"),
depois rode nesta pasta:
    python -m venv .venv
    .venv\Scripts\pip install edge-tts
